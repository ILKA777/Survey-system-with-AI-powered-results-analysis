Фронт для проекта на React
Что может:
1. Окно входа
2. Создание опросов
3. Создание голосований
4. Аналитика
5. Шаблоны опросов
6. Ссылки и qr-коды для опросов
7. Возможность голосовать по ссылке без логина

Запуск на локалхосте: npm run dev
